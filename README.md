🏥 Siddhartha Health And Multicare Pvt. Ltd.

A modern, responsive healthcare clinic website built using React + Vite, designed to showcase doctors, specializations, services, and enable easy appointment booking via WhatsApp.

🚀 Live Demo

🔗 Website: https://shmulticare.com.np/

📍 Location: Bhairahawa, Nepal

📌 Features

⚡ Fast and lightweight (Vite-powered React)

📱 Fully responsive (mobile, tablet & desktop)

👨‍⚕️ Doctor listing with specialization cards

🩺 Clinic services & departments section

📍 Google Maps integration

💬 WhatsApp appointment booking

🌐 SEO-friendly structure

🎨 Clean UI with reusable components

🛠️ Tech Stack

Frontend: React.js

Bundler: Vite

Styling: CSS / Flexbox / Media Queries

Hosting: Netlify

Icons: Font Awesome / React Icons

Maps: Google Maps Embed


⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/your-username/clinic-website.git

2️⃣ Install dependencies
npm install

3️⃣ Run the development server
npm run dev


The app will run at:

http://localhost:5173

🏗️ Build for Production
npm run build


This will generate a dist/ folder (required for Netlify).

🌍 Deploy on Netlify

Build Command

npm run build


Publish Directory

dist


You can deploy via:

Netlify Drag & Drop

GitHub + Netlify CI/CD

📱 WhatsApp Appointment Feature

Appointments are redirected to WhatsApp using:

https://wa.me/<phone-number>?text=<encoded-message>


Example:

https://wa.me/97798XXXXXXXX?text=I want to book an appointment
